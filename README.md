## Descripción

Backend completo para automatizar la atención de clientes de spa vía WhatsApp. Integra inteligencia artificial para procesamiento de lenguaje natural, pasarela de pagos y gestión de agenda en tiempo real.

## Stack

- Node.js + Express
- PostgreSQL + Prisma ORM
- WhatsApp Business API (Meta)
- OpenAI API (GPT)
- MercadoPago
- Google Calendar API
- Zod + Helmet

## Funcionalidades principales

- 🤖 Chatbot con IA para atención automática 24/7
- 📅 Reservas automáticas con selección de servicio, fecha y especialista
- 💳 Pagos integrados con MercadoPago
- 📆 Sincronización con Google Calendar
- 📣 Motor de campañas masivas con segmentación
- 🔒 Máquina de estados para conversaciones con bot pausable
